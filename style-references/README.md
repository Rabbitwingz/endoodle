# Style reference images

Drop 3–6 of your best on-brand Enparadigm illustrations in this folder
(`.png`, `.jpg`, `.jpeg` or `.webp`, ideally under ~2 MB each). They're sent
to the AI with **every** request as visual examples of the house style.
Example images work much better than a written description.

- Leave the folder empty (only this README) to generate from the master prompt alone.
- Only the first 10 images (in alphabetical order) are used.
- Every image adds a little to the cost and time of each generation.
- Commit the images to GitHub and Vercel redeploys with them automatically.
